# Hi, I'm Marcelo Sant'Anna

Senior Software Engineer focused on backend engineering, software architecture, platform engineering, and cloud infrastructure.

I build maintainable systems and delivery platforms using Java, Spring Boot, Python, infrastructure as code, containers, and observability practices. My work and studies connect application design with the operational concerns required to run software reliably.

## Areas of expertise

- **Backend engineering:** Java, Spring Boot, Python, REST APIs, GraphQL, JPA
- **Architecture:** Hexagonal Architecture, domain-oriented design, modular systems, integration patterns
- **Platform and cloud:** AWS, Azure, Terraform, Kubernetes, Helm, Argo CD, Backstage
- **Quality:** JUnit, Cucumber, BDD, automated testing
- **Observability:** OpenTelemetry, Prometheus, Grafana, Jaeger, structured logging

## How I approach engineering

- Start from the problem and business constraints, not from the framework.
- Keep business rules independent from infrastructure whenever the complexity justifies it.
- Treat testing, delivery, security, and observability as part of the architecture.
- Document decisions and trade-offs so systems remain understandable as they evolve.
